Battery Health Checker

A PowerShell script that reads your Windows battery report and shows your battery health as a percentage.

Click the button below to download the script.
Download battery-health.ps1

How to run it

  1. Open PowerShell in the folder where the file was saved (usually Downloads).
  2. Windows marks downloaded files as untrusted, so unblock it once: 
    Unblock-File .\battery-health.ps1
  3. Run it: 
    powershell -ExecutionPolicy Bypass -File .\battery-health.ps1

Requires Windows 10/11 with an English display language. No administrator rights needed. You can read the script before running it: view the source.
